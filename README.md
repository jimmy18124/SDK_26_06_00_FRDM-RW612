# SDK 26.06.00 for FRDM-RW612

NXP MCUXpresso SDK 26.06.00 package for the FRDM-RW612 development board.

This repository contains the board examples, device support, CMSIS, RTOS,
middleware, tools, documentation, manifests, and software notices included in
the SDK package. IAR build output and other generated build files are excluded
by `.gitignore`.

The original license and software notices are retained in
`LA_OPT_NXP_Software_License.txt` and `COPYING-BSD-3`.
